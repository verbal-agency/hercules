# Project agent instructions

Repository-scoped skills live in `skills/` because this execution environment protects `.agents/` and `.codex/` from writes.

- Use `skills/develop-hercules-screenplay/SKILL.md` for Hercules research, canon, treatment, screenplay, scene breakdown, shot planning, and production handoff work.
- Use `skills/higgsfield-film-production/SKILL.md` for Higgsfield preparation, prompting, model routing, generation, or review.
- When both apply, finish story and provider-neutral shot decisions first, then compile the approved shot through the Higgsfield skill.
- Use the `cycle` skill when advancing roadmap goals; these project skills refine domain behavior but do not replace the Cycle contract.
